# BaguetteSub Marketing Site

Pitch-ready single-page marketing site for **BaguetteSub Restaurant** (East Legon, Accra). Built with Vite, React, TypeScript, and Tailwind CSS.

Menu items and hours are illustrative demo content.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

- `npm run dev` — local development server
- `npm run build` — production build to `dist/`
- `npm run preview` — preview the production build
